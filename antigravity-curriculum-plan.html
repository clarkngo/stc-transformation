Antigravity in the STC Curriculum

Drafted from the Sep 16 conversation with Spencer Liu (Google). This is not a proposal to replace Claude Code — it's a plan for where Google Antigravity fits alongside it: a lower-stakes harness for students who are still learning to work with an agent, with Google ADK as the escalation path once a workflow needs to be custom-built.

September 16, 2026 Draft — not yet decided

1. Recommendation

Add Antigravity as the student-facing default; keep Claude Code where it already sits
Recommendation: pilot Google Antigravity as the primary agent harness for students in AI 410 / AI 420, specifically for the weeks where the point of the exercise is learning to work with an agent — including recovering from its mistakes. Leave Claude Code as the internal STC default (per the Sep 1 tooling decision) for faculty work and for any capstone-stage work where reliability matters more than the learning value of friction.
Why this isn't an either/or
Spencer's own framing draws the line for us: Claude Code is "mature and complete," which is exactly why it's a weaker teaching tool for the specific skill Google is hiring for — noticing when an agent is wrong and knowing what to do next. Antigravity needing more active attention is a feature for a classroom, not a bug. The free tier's generous token allowance also matters for a cohort of students, where Claude Code usage is metered against STC's own budget.
🧱

2. The Three-Tool Stack

Each tool has a different job, not a ranked "best tool" list
Antigravity
Learning harness
Default for students. Free-tier token allowance is generous enough for a full cohort. Handles generic, well-scoped tasks.
Google ADK
Escalation path
When a task needs a customized agentic workflow Antigravity can't fulfill generically, students (or faculty) build it directly in ADK.
Claude Code
Faculty / production default
Stays the internal STC default per the Sep 1 decision. Mature, low-friction — the right tool once reliability matters more than the learning value of debugging an agent.
📍

3. Where It Fits in the Course Map

Three named options from the conversation, not yet narrowed to one
Option A
Fold it into AI 410 (AI Engineering) and AI 420 (Agentic AI) directly — Antigravity becomes the harness for specific HOS weeks that focus on agent error-recovery and prompt-engineering breadth, alongside the existing 10-week HOS framework.
Option B
Stand up a dedicated Agentic Engineering / Agent Harness / Agent System course, with Antigravity + ADK as its core toolchain and the Forward-Deployed-Engineer multi-agent evaluation pattern as a unit.
Option C
Use CityU-X as the staging sandbox (already proposed in the Sep 1 meeting) to pilot Antigravity-built student projects before anything touches production — keeps the blast radius of a student's agent mistake contained.
These aren't mutually exclusive — C is an infrastructure choice that supports either A or B. The open question is A vs. B: extend the existing AI 410/420 sequence, or carve out a new course.
🗺️

4. Phased Rollout

Crawl-walk-run, not a term-one switch
Phase Scope
1. Faculty pilot Faculty (not students) build one HOS-style module in Antigravity, hit the ADK escalation path at least once on purpose, and log where it broke compared to the equivalent Claude Code workflow.
2. Single-cohort trial Run one AI 410 or AI 420 section with Antigravity as the default harness for 2–3 HOS weeks, staged on CityU-X. Compare completion rate and error-recovery quality against the Claude Code cohort from the same term.
3. Decide A vs. B Using Phase 2 results, decide whether Antigravity stays folded into AI 410/420 or becomes the anchor for a standalone Agentic Engineering / Agent Harness course.
4. Scale Roll the chosen structure out across all AI 410/420 sections; fold the certifications (Google AI Professional Certificate, Anthropic/Pearson VUE) into the same track as optional stretch credentials.
⚠️

5. Open Questions & Risks

Unresolved as of this draft
Token limits under real load
"Generous on the free tier" hasn't been tested against a full cohort running the same HOS week simultaneously — needs a real trial, not just Spencer's account of it.
Grading consistency
If Antigravity and Claude Code cohorts are graded on the same rubric, error-recovery behavior needs to be assessed the same way regardless of which harness surfaced the error.
Two harnesses to teach and support
Faculty already just settled on Claude as the internal default (Sep 1). Adding a second, student-facing harness means maintaining documentation and troubleshooting for both.
✅
