Overview
Welcome to Module 7 — plan before you build

Goal: No project code this week, on purpose. Plan the way a small real-world team would, using a lightweight version of Scrum — the same framework a lot of real software teams use to plan short, iterative chunks of work. You'll actually build in Modules 9–10.

📚
Reading — Scrum-lite & Example Project
How to plan this project
~15 min

The syllabus's Team/Term Project section covers a worked example project ("Study Buddy," an AI study assistant touching all 4 HOS) and a 4-piece Scrum-lite framework: Product Backlog, Sprint Planning, Standups, and Sprint Review. Read it before starting the activity below.

🛠️
Project Work Time
Write your product backlog, and set up a PM tool

Write your backlog as user stories: "As a [user], I want [capability], so that [benefit]." Doesn't need to be complete or ordered — get every idea onto the list. Then set up a free project management tool to track it — GitHub Projects is recommended since it's already tied to your repo, but Trello or Notion work too. Not sure where to start scoping?
