Course Description

AI Engineering applies rigorous software engineering principles to the development and deployment of autonomous, learning-based systems. This course emphasizes leveraging Large Language Models (LLMs) within purpose-built software solutions to address real-world business challenges. Students will explore system architecture for agent development and integration, context engineering through Retrieval-Augmented Generation (RAG) and vector databases, and best practices for deploying and monitoring AI models in production environments. The curriculum also covers probabilistic logic for handling nondeterministic outputs. Learners gain hands-on experience building a full-stack AI solution, focusing on asynchronous data processing, push-based AI notifications, and seamless integration of vector stores for dynamic RAG applications. Mastery of these concepts will equip students to design and implement robust AI-powered applications using full-stack AI.

Prerequisites

CS 352 — Discrete Mathematics and Data Structures in Computing (NS), and DS 479 — Algorithms for Machine and Deep Learning.

Course Outcomes

As a result of this course, students will know or be able to do the following:

  1. O1 — Define and explain the essential components of full-stack AI systems, such as LLM architecture, agentic loops, and the differences between prompt engineering and context engineering.
  2. O2 — Design and implement a Retrieval-Augmented Generation (RAG) pipeline using vector databases to deliver context to autonomous agents.
  3. O3 — Analyze and break down the multi-layered architecture of agent-driven applications to identify and address potential bottlenecks in asynchronous data processing and nondeterministic reasoning.
  4. O4 — Evaluate and critique the performance and reliability of production AI models using appropriate observability tools and metrics for assessing probabilistic outputs.
  5. O5 — Develop a fully functional, agent-driven mobile application that seamlessly integrates real-time notifications and persistent vector storage into a comprehensive full-stack solution.

Core Concepts & Tools

Students build a single full-stack AI application incrementally across the term, gaining hands-on experience with:

  • Full-stack AI system architecture: a frontend client, a backend API holding the model credentials, and an LLM provider, communicating over HTTP
  • LLM architecture and the agentic loop: structured tool calling, multi-turn reasoning, and the difference between prompt engineering (wording a single request) and context engineering (assembling what the model sees before it responds)
  • Context engineering via Retrieval-Augmented Generation (RAG): text chunking and embeddings, vector database storage and similarity search (Chroma), and grounding model output in retrieved content
  • Probabilistic logic and guardrails: validating and retrying against nondeterministic model output using schema-checked, self-correcting wrappers
  • Asynchronous data processing: background job queues (Redis/RQ) and status polling, so long-running work does not block the user-facing app
  • Mobile clients and push-based AI notifications: a React Native (Expo) client that registers for and receives push notifications when background work completes
  • Observability and evaluation of production AI systems: request tracing, latency and token/cost metrics, and faithfulness scoring for probabilistic output (Langfuse)
  • Deployment: containerizing and deploying the API, worker, and vector store as separate services to a live host

Course Assignments and Grading

AssignmentWeightWhat it covers
Weekly Hands-On Labs
Weeks 1, 2, 3, 6, 7, 8		 25% Each non-milestone week has its own hands-on guide built around a working starter app and one specific implementation task — e.g. adding a real tool to the agentic loop, writing a guardrail validator, or wiring push notifications into the mobile client. Students submit each week's working code with a short note on what they built and how they verified it.
RAG Pipeline Implementation
Week 4		 15% Implement retrieve() to embed a query, run a similarity search against a local vector database, and inject the retrieved chunks into the agent loop as grounding context. Grading compares the agent's answer to a domain question with and without retrieval enabled.
Architecture Review Checkpoint
Week 5		 15% At the course midpoint, diagram the full-stack architecture of the app as built so far and identify at least one bottleneck each in asynchronous data processing and nondeterministic/probabilistic reasoning, proposing a concrete mitigation for each.
Observability & Evaluation Report
Week 9		 10% Instrument agent and retrieval calls with request tracing, inspect real traces (latency, token/cost, faithfulness score), and critique a deliberately out-of-scope query.
Capstone: Full-Stack AI Application & Live Demo
Week 10		 25% Integrate every prior week's component — RAG, guardrails, asynchronous ingestion, mobile push notifications, and tracing — into one deployed application, and give a 5-minute live demonstration.
Instructor Determined Assignments 10% Collaboration, discussion, participation, peer review, and other ongoing activities as determined by the instructor.
