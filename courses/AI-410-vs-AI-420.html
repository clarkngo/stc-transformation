AI 410 vs. AI 420

Same credits, prerequisites, length, and grading Different question Sep 24, 2026 — AI 420 is a design (v0.2), not yet built
Compares the two course pages as they stand: AI 410: AI Engineering (built and deployed) and AI 420: Agentic AI (course design v0.2). Both follow the BSAI Course Design Constraints: the official description and outcomes are fixed, everything runs in GitHub Codespaces, and free tiers come first.
In one line: AI 410 builds the system around an AI model. AI 420 builds software where the model decides what to do next. Same rubric, same weights, same 4-HOS shape, but the thing students judge changes from "does the app work and can you explain the code" to "what did the agent do, and why."

What each course is really about

AI 410

The model is a component

Students build the same chat assistant all term and keep adding the parts that make it dependable in front of real users: retrieval so it answers from real data, guardrails so bad output doesn't crash it, background jobs so it doesn't freeze, and tracing so problems are visible. The model is one part inside an engineered app.

AI 420

The model is the decision-maker

Students build software that picks a tool, looks at what came back, notices when it went wrong, and tries again without a person clicking "next." The hard skill is no longer wiring components together. It is judging behavior that changes from run to run.

The two lists pair off: O1 is "know the parts" in both, O3 is "diagnose" in both, and O4 is "measure" in both. What changes is the object: an app's architecture and bottlenecks in 410, an agent's reasoning trace in 420. The agent itself is the biggest overlap: AI 410 O1 introduces agentic loops, and AI 420 O1 goes deeper on what an agent is made of.

How AI 420 builds on AI 410

Almost every AI 420 unit takes an idea AI 410 introduced and changes how the student meets it:

AI 410 HOS 1The agentic loop, scaffolded with an AI coding assistant.
→
AI 420 HOS 1The same loop written by hand, with no framework hiding it, so the four components can be pointed at in the code.
AI 410 HOS 1Function calling with two simple tools.
→
AI 420 HOS 2Tools that touch the outside world (API, browser, database), served over MCP, with tool errors returned to the model as observations instead of crashes.
AI 410 HOS 2Chroma retrieval: the agent reads documents.
→
AI 420 HOS 2Chroma as long-term memory: the agent writes what it learned so a later run can recall it.
AI 410 HOS 3Guardrails: validate and retry a tool's arguments.
→
AI 420 HOS 3Self-correction: reflection, retry with a corrected argument, repeated-call detection, and step and cost budgets.
AI 410 HOS 4Langfuse tracing for latency and a faithfulness check.
→
AI 420 HOS 3–4The same Langfuse UI, now read to diagnose failures, then extended with success rate, cost per task, and an LLM judge.

Same assessment system, different things to judge

Both courses use the same four-stage CEAU cycle (Create/Scaffold, Evaluate, Analyze, Understand & Refine) and identical weights: Muddiest Point 5%, Concept Debate 5%, four HOS at 12.5% each (50%), four Application Challenges at 5% each (20%), and the capstone 20%. Students and faculty moving between the courses see one grading system.

Worth deciding

  1. The prerequisites don't chain, but the setup does. Both courses list CS 352 and DS 479. AI 420 reuses AI 410's Gemini key, Codespaces workflow, and Langfuse, yet AI 410 is not an approved prerequisite for AI 420, and the approved prerequisites can't be changed. A student can arrive in AI 420 without ever having done any of that setup. Decide how AI 420's first week covers them, for example a short setup checklist pointing to the Account & Service Setup Guide and the Concept Companion.
  2. Two courses teach the agentic loop. AI 410 HOS 1 introduces it and AI 420 HOS 1 rebuilds it by hand. That is deliberate and both course descriptions require it, but a student who took both could find HOS 1 repetitive. Make the difference explicit in AI 420's opening: last time you scaffolded it, this time you write it.
  3. Free-tier load is heavier in AI 420. One AI 410 chat turn is one or a few model calls. An AI 420 evaluation run multiplies calls per task (the agent, a simulated user, and a judge). Constraint 3 says to estimate calls per student per run against the free-tier rate limits before building, so do that estimate before the HOS 4 guide is written.
  4. The materials aren't comparable yet. AI 410 is fully built and AI 420 is a design. This page compares design to design; revisit it once AI 420's guides and starter code exist.
