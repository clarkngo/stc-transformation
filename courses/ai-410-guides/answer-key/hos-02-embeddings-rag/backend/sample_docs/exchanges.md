# Exchanges

Northwind Outfitters accepts exchanges within 45 days of delivery — longer than our 30-day return window, since we'd rather swap a size than issue a refund. The item must be unused and in its original packaging, same as a standard return.

To start an exchange, use the return portal and select "Exchange" instead of "Refund," then choose the replacement size or color. If the replacement item costs more, you'll be charged the difference; if it costs less, the difference is refunded to your original payment method.

Exchanges ship free both ways — we cover the return shipping label and the outbound shipping on the replacement item, regardless of order total.
