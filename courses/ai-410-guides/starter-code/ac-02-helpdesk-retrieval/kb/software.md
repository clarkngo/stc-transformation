# Software for Students

## Microsoft 365
All current students can install Microsoft 365, including Word, Excel, PowerPoint, and OneDrive, on up to five computers and five phones at no cost. Sign in at office.com with your campus email address and choose "Install apps". Your license ends 30 days after you stop being enrolled.

## Specialty software
Software needed for a specific course, such as statistics, design, or engineering packages, is listed on the course page in Canvas. Most of it runs in the virtual computer lab at vlab.riverbend.edu, which works in any web browser, so you do not need to install it. Ask your instructor if a program is missing from the virtual lab.

## Installation problems
If an installation fails, restart your computer and try again before doing anything else. Make sure you have at least 10 GB of free disk space. Chromebooks cannot install Microsoft 365 desktop apps; use the web versions at office.com instead.

## Antivirus
Students do not need to buy antivirus software. The protection built into Windows and macOS is enough for campus use. Riverbend does not provide or support any third-party antivirus product.
