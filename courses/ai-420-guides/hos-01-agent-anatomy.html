HOS 1 — Anatomy of an Agent: Inference vs. the Agentic Loop

Est. 3–4 hrs Outcome 1 Scaffolding: full prompt given 12.5% of final grade
Draft — in faculty testing. The code for this HOS has been checked offline (tools against the real free APIs, agent logic against a scripted stand-in model), but not yet run end to end against Gemini. Faculty running it: note anything that breaks or takes longer than the estimate.

Goal

Answer the same multi-step questions two ways — one plain LLM call, then an agent loop you build yourself with no framework — so you can point at the exact lines where reasoning, planning, tool use, and memory happen. Then rebuild it in Google ADK and find the loop ADK hides from you.

What you'll need

  • Starter code: this HOS's starter-code folder. Copy it into your portfolio repo (made from the portfolio template in Week 1) as its own folder, then open the repo in GitHub Codespaces. Dependencies install automatically.
  • Your free Gemini API key (the same one from AI 410, no credit card) from aistudio.google.com/apikey. In the HOS folder: cp .env.example .env, then paste it in as GOOGLE_API_KEY.
  • An AI coding assistant in your Codespace (Antigravity, Claude Code, or equivalent)

Reference reading (optional, before you start)

  • agent-development hos01 — greeting agent: the smallest possible ADK agent.
  • agent-development hos02 — tool agent: an ADK agent with function tools, the same shape as adk_research_agent/.

This HOS is graded across four stages instead of on code correctness alone. Each stage below says exactly what to submit.

1Create / Scaffold

Not graded on its own — this is the starting point, not the deliverable.

The starter already has three working tools (research/tools.py: Wikipedia search, Wikipedia intro, calculator), a single-call baseline (research/baseline.py), five test questions (tasks.json), and a comparison script (compare.py). First run the baseline alone to see what plain inference does with a multi-step question:

python -m research.baseline "How many years before the first iPhone was the Space Needle completed?"

Then prompt your AI assistant to build the loop. Use this prompt as given:

In research/react_loop.py, write a ReAct agent loop by hand using the
google-genai SDK. Do not use any agent framework.
- Expose run(question, max_steps=8, verbose=False) -> dict with keys:
  answer, steps, tool_calls, tokens, seconds, log.
- Import TOOLS and TOOLS_BY_NAME from research/tools.py, and MODEL,
  SYSTEM, get_client, count_tokens from research/common.py.
- Pass the tool functions in GenerateContentConfig(tools=...) and turn
  OFF automatic function calling, so this code runs the loop itself.
- Each step: call the model with the full message history. If it asks
  for function calls, append its turn to the history, run each tool,
  and append the results as function responses. If it doesn't, return
  its text as the final answer.
- If max_steps runs out, return an honest "couldn't finish" answer
  instead of looping forever.
- Record every tool call (name, args, result) in log.
- Add a __main__ block that runs a question from the command line.

Then run all five questions through both approaches:

python compare.py --verbose

2Evaluate

The critical gate — is the AI-produced result actually correct?

Check every answer from compare.py against the expected line printed under each question. At minimum, work out:

  • Which questions did the baseline get right anyway, and why? (Some facts are in the model's memory. Being right from memory isn't the same as being right from evidence.)
  • For the agent: did it use the calculator for the arithmetic, or do the math in its own reply? Open the --verbose step log to check.
  • What does the agent cost you? Compare steps, tokens, and seconds against the baseline in the summary table.
  • Set max_steps=2 and rerun one question. Does it stop honestly, or pretend it finished?
Submit
  • The comparison table from compare.py, and a short note: which answers were right, which were right for the wrong reason, and what the agent cost compared with the baseline.

3Analyze

Why does this work, mechanically?

Pick one of these and explain it in your own words:

  • Point to the exact line in react_loop.py where each of the four components lives: reasoning, planning, tool use, and memory. For memory, explain why the whole history is sent again on every step, and what that does to token count as the loop goes on.
  • Run the ADK version (adk web from the HOS folder, pick adk_research_agent) on the same question, and open its Events tab. Match each event to the step in your own loop that does the same job. What does ADK do that your loop doesn't?
Submit
  • A short written walkthrough of the one you chose. If you picked the ADK comparison, include a screenshot of the Events tab.

4Understand & Refine

The mastery check — by hand, no AI assistance for this stage.

ReAct plans one step at a time. Write the other pattern yourself: plan-and-execute, in research/plan_execute.py.

  • First, one model call returns the whole plan as a JSON list of 2–4 steps. (Hint: response_mime_type="application/json" with response_schema=list[str].)
  • Then run each step through your own react_loop.run() with a small step budget, passing along what earlier steps found.
  • Finally, one call writes the answer from those findings alone.
  • Return the same dict shape as react_loop.run(), plus the plan, so python compare.py --with-plan works.
Submit
  • Your plan_execute.py.
  • The compare.py --with-plan table, and two or three sentences: on these questions, which pattern was more accurate, and which was cheaper?
Honor code

Tick one when you submit: ☐ "I wrote the Stage 4 code myself, without AI assistance, under the CityU academic integrity policy." or ☐ "I used AI for part of Stage 4. Here's what I used it for and why."

Disclosed AI use earns partial credit on this stage instead of zero, so saying so honestly always costs less than hiding it. The Week 5 cold build is where independent skill is checked directly.

Common snags

  • A Wikipedia tool returns 403 Forbidden — Wikipedia blocks requests without a descriptive User-Agent that includes contact information. The starter's HEADERS already has one. If your AI assistant rewrote the tools, check it didn't drop that header.
  • The model answers without calling any tool — check that automatic function calling is actually off and that the tools are in the config. With automatic calling on, the SDK runs tools for you and your loop never sees them.
  • GOOGLE_API_KEY is not set — the .env file must sit in the HOS folder itself (next to tasks.json), not in research/.
  • adk web lists folders that aren't agents — that's expected. It shows every folder in the directory you started it from. Pick adk_research_agent.
  • 429 RESOURCE_EXHAUSTED — you hit the free tier's per-minute limit. Wait a minute and rerun; the scripts' --pause option adds a gap between runs.
  • Codespaces doesn't pick up the devcontainer — Codespaces only reads .devcontainer/ at the root of a repo. Use the portfolio template (its devcontainer covers all four HOS), or make this HOS folder the root of its own repo.
