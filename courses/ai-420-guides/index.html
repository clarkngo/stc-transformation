AI 420: Agentic AI — Hands-On Guides

Four Hands-On Skill (HOS) units, Weeks 1–4, each graded on the CEAU cycle (Create/Scaffold → Evaluate → Analyze → Understand & Refine). Each one adds a working agent to the student's portfolio repo. The help students get from the prompt fades as the units go on, per the AI 410 design review: HOS 1 gives the full prompt and HOS 4 gives only the goal. Everything runs in GitHub Codespaces on free tiers, per the BSAI Course Design Constraints.
HOS 1 · Week 1 · O1

Anatomy of an Agent

One LLM call vs. an agent loop you write by hand, then the same agent in Google ADK. Plan-and-execute by hand.

Est. 3–4 hrsFull prompt
HOS 2 · Week 2 · O2, O1

Custom Tools, MCP & Memory

API, browser, and database tools on your own MCP server, plus short- and long-term memory.

Est. 3.5–4.5 hrsPartial prompt
HOS 3 · Week 3 · O3

Traces, Failure Diagnosis & Self-Correction

Find five planted failures from traces alone, then add guards so the agent recovers on its own.

Est. 3–4 hrsSpec only
HOS 4 · Week 4 · O4

Multi-Agent Orchestration & Evaluation

A coordinator + specialists, tested by a simulated customer and an LLM judge: success rate, cost per task, latency.

Est. 4–5 hrsGoal only
