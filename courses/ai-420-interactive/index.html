Interactive Lessons & HOS Simulators

Two-week interactive lessons for each Hands-On Skill — lecture, Muddiest Point, Concept Debate, the CEAU stages, Application Challenge — plus four browser simulators that show agents looping, choosing tools, failing, and being evaluated, before students build them.

About these pages

AI 420 is an upcoming BSAI course — these are course materials, not yet offered to students. The lessons pair with the hands-on guides, whose starter code and answer keys have been checked offline and are in faculty testing. Everything follows the course design constraints: fixed official description and outcomes, GitHub Codespaces, free tiers first.

How every HOS runs — two weeks
Week 1 · Build & judgeLectureThree short parts, each with a quick check.
Week 1Muddiest PointFour-field structured reflection. Graded.
Week 1Concept DebateAssigned side → argue the opposite → synthesis. Graded.
Week 1Create → EvaluateAI-assisted scaffold, then deliberate testing.
Week 2 · Explain & masterAnalyze → RefineExplain one mechanism; extend by hand, no AI.
Week 2Application ChallengeTransfer the judgment to a new scenario.
