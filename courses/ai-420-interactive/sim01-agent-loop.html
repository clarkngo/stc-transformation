What this teaches

  • A single call's right and wrong answers look the same. Run it five times: the confidence never changes, the answer sometimes does.
  • The loop is where the four components live: each model call is reasoning, the tool calls are tool use, the growing message list is memory, and plan-and-execute makes planning visible.
  • Agents cost more. Compare tokens across approaches — then ask whether the question needed an agent at all.
  • The step budget is a promise to stop honestly. Set it to 2: the loop says it couldn't finish instead of guessing.
  • Without a calculator, "right" can be luck. Turn it off and the agent does math in its reply — usually right, occasionally not, never checked.
