What this teaches

  • The description is the interface. Make query_database's description vague ("Look up stuff") and it steals requests from the narrow tools.
  • Protect twice. Either protection alone stops most attacks; only with both off does "cancel order 1003" actually change data.
  • Short-term memory ends with the session; long-term memory must be scoped. Turn scoping off and Marcus hears Ana's preference.
