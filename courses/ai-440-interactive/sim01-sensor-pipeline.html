What this teaches

  • A stuck sensor looks calm. In shadow mode it only misleads the dashboard; in twin mode the heater stays on and the true temperature climbs past the limit.
  • Validation catches what you wrote rules for — the stuck value and the spike — and the twin falls back to safe behavior.
  • Real-time is a number: four hops × the per-hop delay. Push it up and the twin reacts to old news.
