IS 201 Revamp: Week-by-Week Guides

The actual build behind the IS 201 Revamp Design Brief — a CityUX microcredential pilot of Fundamentals of Programming, redesigned so grading rewards reading, judging, and directing code (Analyze / Evaluate / Create) instead of typing it from memory. This page is the single place to find every guide as it's built, so nothing here gets scattered across separate pages.

🚢 Maritime — MVP domain, live 🛒 Marketing / E-commerce — MVP domain, live 🏥 Healthcare — planned 💳 Finance / Fintech — planned

Why Maritime + Marketing/E-commerce first

Maritime ties directly into STC's existing Blue Tech & Maritime initiative — real case studies and subject-matter expertise are already on hand, not invented for this pilot. Marketing/E-commerce sits next to it as a low-context-cost contrast: no specialized domain knowledge needed to follow along, so it's a good check that the domain-switch mechanic itself (not just the maritime content) actually works. Healthcare and Finance/Fintech stay in the long-run domain set but aren't built until this MVP validates the approach — see the Domain Switch section of the brief.

☁️ Runs on GitHub Codespaces — no local install

Every guide runs in the browser via a real .devcontainer/devcontainer.json in this repo, not a local Python/VS Code setup. This continues the direction already flagged in the Sep 1 tooling meeting notes and CityUX's own execution plan's click-to-launch Codespaces pattern for lab content — see Week 1 for the pilot test of it.
