Week 4 — Dictionaries & Sets

Est. 2–3 hrs CO2 Pilot domains: Maritime & Marketing/E-commerce 🎯 Diff/Debug Sprint — graded

Goal

Model a real domain record — with nested data, not just flat values — as a Python dictionary, and practice justifying why you shaped it the way you did. Then run a Diff/Debug Sprint on the single most common dictionary mistake: a typo in a key name.

What you'll need

  • Your Codespace from a previous week (or a fresh one — setup steps here)
  • Your AI coding assistant, signed in and ready

Steps

  1. Pick your domain lens

    # Prompt you'll give the AI assistant (Maritime lens): # "Write a Python script that stores a vessel record as a # dictionary with a nested 'crew' dictionary inside it, then # prints the captain's name from the nested dictionary."

  2. Model the record on paper first — then have the AI write it

    Before typing anything, sketch what fields belong at the top level vs. nested one level deeper, and why. A vessel's id and engine_temp_c are simple values; its crew is a group of related people — that's the signal it deserves its own nested dictionary rather than flat fields like captain_name, engineer_name.

    Why this matters beyond this exercise

    Every module from here on, you'll be asked more often to justify a design choice, not just produce output that runs. "It works" and "it's the right shape for how this data will actually be used" are different claims — this is the first module where the schema itself is part of what's being evaluated, foreshadowing Module 8's Solution Evaluation Brief.

Common snags

  • "KeyError: 'crew'" instead of the nested key — check that the outer key exists first; if vessel["crew"] itself is misspelled, Python never even gets to the inner lookup.
  • Mixing up dictionaries and lists — a dictionary looks up values by name (vessel["id"]); a list looks up values by position (fuel_data[0]). If you're counting on order, you probably want a list, not a dictionary.
  • Runner says "Loading Python…" for a while — same as previous weeks, first load downloads a real Python runtime.
