Week 8 — Object-Oriented Programming

Est. 2–3 hrs CO5 Pilot domains: Maritime & Marketing/E-commerce ⚖️ Solution Evaluation Brief

Goal

Extend a class through inheritance, and practice the Solution Evaluation Brief: given two working designs for the same problem, judge which one actually fits — not which one is "textbook correct." Then run a Diff/Debug Sprint on the single most common inheritance mistake: a subclass constructor that never calls its parent's.

  2. Solution Evaluation Brief: inheritance vs. composition

    Before writing the subclass, look at two working designs for the same problem and judge which fits better.

    Two candidate designs for the same requirement

    Design A — InheritanceDesign B — Composition
    class CargoVessel(Vessel):
    adds cargo_tons directly onto a subclass. A cargo vessel is a vessel, permanently.    		class Vessel: holds a self.cargo = Cargo(...) attribute instead. A vessel has a cargo configuration, which can change.

    Both run correctly. The Evaluation Brief question isn't "which is more advanced" — it's: can this vessel's cargo role change without it becoming a different kind of object? A vessel that's sometimes loaded with cargo and sometimes running empty or as a passenger ferry fits composition better — its cargo is something it has, not something it permanently is. If the fleet genuinely never reassigns a vessel's role, inheritance is simpler and that's a legitimate reason to prefer it.

    Write one or two sentences recommending A or B for your domain's scenario, with a reason tied to whether the role can change — that's what gets evaluated, not which option you picked.

Common snags

  • Thinking Python calls the parent's __init__ automatically — it doesn't, once a subclass defines its own __init__, that completely replaces the parent's unless you explicitly call super().__init__(...).
  • Not sure whether your domain scenario is "is-a" or "has-a" — ask whether the object could plausibly need to drop or swap that role while staying the same object. If yes, that's a "has-a" signal favoring composition.
