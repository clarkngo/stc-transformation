1. Tooling Evaluation & Strategy

Claude as primary; Cursor subscription winds down end of month
Claude vs. Cursor
Claude is now the primary thinking/building partner — handles context well across long working sessions. Cursor stays on as a backup tool, not the default. This continues the comparison started in the AI Dev Tooling Comparison writeup.
Config format
Noted that Claude reads project instructions from CLAUDE.md, not the AGENTS.md format some other platforms have standardized on — worth keeping in mind when writing docs meant to work across tools.
Decision: wind down the Cursor subscription at the end of the month and rely on Claude day to day, while still checking for academic licensing or discount programs before fully closing the door on it.
📚

2. Curriculum Design & CityU-X Integration

AI 410 / AI 420, hands-on lab guides, and CityU-X as a staging sandbox
Courses in scope
Reviewed course development for the BSAI/CS track: AI 410 (AI Engineering) and AI 420 (Agentic AI).
HOS format
Course modules are structured around progressive Hands-On Sessions (HOS) — architecture diagrams, clear step-by-step tasks, and verifiable code diffs, favored over passive lecturing.
CityU-X as sandbox
CityU-X doubles as a rapid sandbox/staging platform — course materials get piloted and tested asynchronously there before moving to production. Ties back to the platform work in the CityUX hub.
Agentic-workflow concepts
Curriculum for teaching agentic workflows draws on ADK, MCP, A2A, Kubeflow pipelines, and API endpoints — referencing industry architectures and recent consultation insights (including discussions with HK).

3. Addressing Student Retention in IS 201

30–40% DFW rate driving a shift away from heavy-syntax teaching
Root-cause review: introductory programming (IS 201) currently runs a 30–40% Drop/Fail/Withdraw rate. The group traced this back to a teaching methodology that leads with heavy syntax before students see why any of it matters.
Proposed shift
Move to an AI-assisted, practical approach: students use tools like Claude/Gemini to build domain-relevant applications — e.g. business-track students building for their own domain rather than tech-track exercises — while learning to read code diffs and commit histories instead of writing every line from a blank file.
💰

4. Department Budget, Staffing & PM Position

Protecting CityU-X momentum inside a constrained budget
Constraints
Institutional budget is tight, tied to ongoing restructuring and external consulting costs.
Reallocation plan
To protect AI/CityU-X project momentum: reduce general student-worker headcount and redirect the freed budget toward the initiative.
PM position
Pursuing approval for a dedicated Program Manager role, targeting 0.5 FTE funded via PD/STC resources, to give CityU-X initiatives sustained staffing support.
