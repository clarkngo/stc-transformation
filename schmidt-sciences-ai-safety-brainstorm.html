Cluster What it wants Our fit
1. Sandboxes & Testbeds Realistic, reproducible multi-agent environments for empirical safety research. Strong — but heavy build: infra, security review, sustained compute.

The Dean's Reading — Kapoor et al. 2026

What it is
"Open-World Evaluations for Measuring Frontier AI Capabilities" (Princeton, UK AI Security Institute, Johns Hopkins, ANU, Microsoft Research, Georgetown CSET, +others). Introduces CRUX, a methodology for evaluating AI agents on long-horizon, real-world tasks via small-sample qualitative log analysis — not multi-agent safety research itself. Flagship example: an agent autonomously built and published an iOS app through the full App Store review process.
CRUX's 6 norms
Specify the construct being measured · document human interventions · analyze & release logs publicly · add real-time monitoring · run dry runs first · report cost as a first-class metric. Directly transferable to how Cluster 1 testbeds should be built.
The multi-agent data points buried inside it
  • AI Village (April 2025–present): agents given shared goals + group chat, persistent hallucination and coordination failure over months.
  • Cursor browser experiment (Jan 2026): hundreds of agents building a browser collapsed to 2–3 effective agents after early hierarchical coordination broke down.
  • CRUX #1 itself: the single agent spontaneously delegated status-checks to subagents mid-task to cut cost — an emergent, unprompted multi-agent behavior inside a nominally single-agent evaluation.
🎯

Recommended Angle

Cluster 2 — Science of Agent Networks. Seed research question: "When AI agents are organized into large, decentralized groups on real-world tasks, what causes coordination to collapse from many active agents down to a small effective core — and can we predict or prevent it?" Directly generalizes the Cursor "hundreds → 2-3 effective agents" finding into a testable study, using CRUX's own methodology (log-driven, small-sample, qualitative) as the toolset.
Why not Cluster 1

Building a real testbed is a bigger lift — sustained engineering headcount, ~$50K+/yr compute, security review. Harder sell without a track record.

Why Cluster 2

Lower infra bar, can lean on existing scaffolds (OpenClaw-class) and already-published data points as a starting point rather than building from zero.

Infrastructure
An agent scaffold (e.g. OpenClaw-class), isolated compute/VM, logging pipeline. No new platform build needed for the Cluster 2 angle.
Security & admin
CityU IT/security sign-off on agent scaffold permissions; confirm whether CityU has any office able to administer a philanthropic award under a 10%-indirect-cost cap. Unconfirmed — check first.

  • 1
    Run the question-scoping + pilot-design + outreach steps without the deadline pressure.
